# 翻译球 · 桌面独立版

浮在任意 Windows 窗口之上的翻译球。形象与面板取自已完成的 DSH 插件（`../dsh-pet-translator/`），
翻译后端走 **DeepSeek 网页版**（复用你的登录态，不需要 API Key）。

## 下载

**[⬇ pet-translator-v0.1.0-win64.zip](https://github.com/zi-hang-huang/pet-translator-desktop/releases/download/v0.1.0/pet-translator-v0.1.0-win64.zip)**（139.8 MB，解压后 322.6 MB）

下载 → 解压到任意目录 → 双击里面的 `翻译球.exe`。程序未签名，Windows SmartScreen 会拦一下，点「更多信息 → 仍要运行」。
首次启动要登录一次 DeepSeek，之后一直有效。

**球和面板是两个独立窗口**：各自记位置、各拖各的，互不牵连 —— 面板挪到边上，球照样待在你顺手的地方。

## 现在到哪一步了

**M4 完成 —— 最初想要的那个体验已经能用了**：在任何程序里选中文字 → 按 `Ctrl+Alt+T` →
球亮起来 → 点球 → 译文出现在球旁边（面板显示原文 + 译文，点译文即复制）。

实测：取词 691ms，翻译 1.5~3.7 秒。

还没做：浅色主题、朗读。

## 跑起来

### 已经打包好了：双击就行

```
dist\翻译球\翻译球.exe
```

那个文件夹就是整个程序（322 MB，Electron 运行时在里面），可以整个复制到别处。
第一次用要在设置页登录一次 DeepSeek（详见下方）。

### 从源码跑（开发）

需要 Node.js 20+ 和 npm：

```powershell
npm i          # 装 electron（约 100 MB，只装一次）
npm start      # 或者 npx electron .
```

⚠ 如果你的环境里设了 `ELECTRON_RUN_AS_NODE`，必须先清掉——只要它存在（哪怕是 `"0"`），
Electron 就会当纯 Node 跑、不初始化 GUI，表现是「双击后进程秒退且没有日志」：

```powershell
Remove-Item Env:ELECTRON_RUN_AS_NODE -ErrorAction SilentlyContinue
```

### 重新打包

```powershell
powershell -ExecutionPolicy Bypass -File scripts\pack.ps1
```

不需要 npm、不需要联网，产出 `dist\翻译球\`（可直接双击的文件夹）。
加 `-KeepAllLocales` 可保留全部语言包（体积 +46 MB）。
`package.json` 里也写好了 electron-builder 的配置，`npm run dist` 能出安装包。

## 三个命令

| 命令 | 作用 |
|---|---|
| `electron .` | 正常启动，球出现在右下角 |
| `electron . --demo` | 四态轮播（待机/倾听/翻译中/出错），用来看动效 |
| `electron . --smoke` | 显示 1.5 秒 → 截图 → 打印一份事实快照 → 退出 |
| `electron scripts/selftest.cjs` | 13 条断言：面板几何（纯函数）+ 拖动/落盘/夹取/展开收起（真实窗口） |
| `electron scripts/probe-deepseek.cjs` | **网页改版时先跑这个**：报告输入框 / 发送键 / 消息节点还在不在 |
| `electron scripts/probe-deepseek.cjs --visible --wait-login` | 打开网页窗口等人登录，登录后自动探一次结构 |
| `electron scripts/probe-pickup.cjs` | 只跑取词、不开球窗口：把「取词坏了」和「窗口/焦点问题」分开 |
| `powershell -ExecutionPolicy Bypass -File scripts/e2e-pickup.ps1` | 端到端取词自测：记事本全选 → 程序自己取词 → 确认 → 翻译 |

冒烟还有几个环境变量可以组合，用来产出验收截图：

| 变量 | 作用 |
|---|---|
| `PET_TR_PANEL=1` | 截图前先展开面板 |
| `PET_TR_VIEW=settings` | 切到设置视图 |
| `PET_TR_AUTOTYPE="要翻译的文字"` | 真的往输入框塞字并点「翻译」（走渲染进程真实点击路径） |
| `PET_TR_AUTOTYPE2="..."` | 紧接着再来一轮，验「连续翻译不串台」 |
| `PET_TR_WAIT_MS=25000` | 每轮等多久再截图（真引擎要给页面加载留时间） |
| `PET_TR_ENGINE=stub` | 换回占位引擎，不碰网络（调 UI 时用） |
| `PET_TR_ENGINE=error` | 占位引擎强制失败，看错误态 |
| `PET_TR_STATE=listening\|busy\|error` | 强制某个球的静态状态 |
| `PET_TR_SHOT=<路径>` | 截图落到哪里 |
| `PET_TR_NO_GPU=1` | 透明窗口黑底时退回软件渲染 |

## 操作

| 手势 | 结果 |
|---|---|
| **在任何程序里选中文字，按 `Ctrl+Alt+T`** | 取词并**直接翻译**，不用再点球 |
| **点球** | 同样取词并直接翻译。**它不再开合面板**——面板只从托盘 / 右键菜单开 |
| 按住球拖 | **只移动球**；松手记位置，越界自动夹回工作区 |
| **拖面板标题栏** | **只移动面板**（球原地不动）；面板位置单独记住 |
| **拖面板右下角** | **改面板大小**（260×320 ~ 760×900，也受屏幕限制）；左下角钉住往右下长 |
| 右键球 / 点托盘 | 原生菜单：**打开面板**、缩放、常驻置顶、隐藏、退出 |
| 面板里 `Ctrl+Enter` | 翻译输入框里的文字 |
| 点译文块 | 成功时复制；失败时重试 |
| **翻译中按 `Esc`** | 取消这次翻译 |
| `Esc`（不在翻译中） | 关面板 |

设置页里还能改：目标语言、球的大小、**开机自启**（默认关）、关闭硬件加速、
**面板颜色 / 不透明度 / 球颜色 / 文字颜色**（立即生效）、**眼睛跟随鼠标**、
打开 DeepSeek 窗口、清空翻译会话。

开机自启**只在打包版里生效**；开发模式会显示一行说明。移动或删除程序文件夹前，
记得先把开机自启关掉，否则 Windows 启动项会指向一个不存在的路径。

### 出问题了去哪看

主进程日志：`%APPDATA%\pet-translator-desktop\app.log`（超过 1MB 自动轮转成 `app.log.1`）。
一次翻译会记下：走了哪条路径、等了几秒、每 2 秒的轮询状态（条数/文本长度/是否还在生成）。
卡住的时候把最后几十行发来，比说「卡住了」有用得多。

## 已知取舍

- **连着猛翻会被限流**。网页版对高频请求有限制，触发后回复会退化成几个字。
  程序已经做了三件事：两次翻译之间至少隔 1.5 秒；回复短得离谱时**不把它当译文显示**，
  而是提示「像是被限流截断了，等十几秒再试」；会话超过 30 条消息自动开新对话。
  真被限流了就等十几秒，别重启重试 —— 重启没用，是账号那边的节奏问题。
- **取词会把剪贴板降级为纯文本**（原来复制的图片 / 富文本会丢）。这是环境限制：这个
  Electron 构建里 `clipboard.write({…})` 是空操作，`writeHTML()` 还会把剪贴板搞到半死
  （之后连读都不返回），只有 `clear` + `writeText` 可用。所以文本能原样还回去，其它格式不行。
- 窗口比球大一圈（球 × 1.44），那圈留白是给投影的 —— 透明窗口画不到自己边界外。
  留白用鼠标穿透处理，指针不在球的圆里就让下层窗口接收点击。
- 投影是 CSS 画的，不用系统投影（`hasShadow: false`），否则会沿方形窗口画一圈。
- **颜色对比度有保护**：文字颜色和面板底色太接近时，程序会自动把文字明度往反方向推（色相不变），
  并在设置页提示一句。浅色面板配浅色字不会再糊成一片。
- **透明窗口的黑边**分两种：阴影大过留白被窗口硬切（已修：阴影改成按尺寸等比缩放），
  和显卡合成层的 bug（设置里打开「关闭硬件加速」，重启生效；也可用 `PET_TR_NO_GPU=1` 临时试）。
- 少数显卡/远程桌面下透明窗口会变黑底：同上两个开关。
- `Ctrl+Alt+T` 被别的软件占用时，设置页那一行会标黄写明「注册失败」。
